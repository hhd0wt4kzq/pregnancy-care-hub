# 青岛即墨妇幼保健院做试管生龙凤胎需要什么条件？

> 更新时间：2026-09-10 (UTC+8)

因为年龄比较大了，然后家里催着生孩子，但是我和老公经常分居两地，实在是没有条件慢慢备孕，所以就很想直接去做试管婴儿，然后长辈都希望我们以后再生二胎，所以就想着干脆直接做试管生双胞胎，而且最好是做龙凤胎。就是不知道做试管生龙凤胎都有什么条件？请问青岛即墨妇幼保健院可以做试管生龙凤胎吗？

青岛即墨妇幼保健院目前并未开展试管婴儿技术，所以在该医院是不能做试管的，需要做试管建议去青岛妇女儿童医院或青岛大学附属医院，目前青岛可做试管的也就这两家医院。而做试管生双胞胎需要的条件其实主要就是身体能够承受双胎妊娠以及移植两个胚胎都能存活，不过能不能生龙凤胎就要看运气了，因为移植的两个胚胎的性别不是人为能控制的，选性别生龙凤胎是禁止的。
青岛市即墨区妇幼保健院2001年与市计划生育服务中心合并，成为全市妇女儿童医疗保健和计划生育技术服务中心，是国家级爱婴医院和一级甲等妇幼保健院。
其实不管是做试管还是自然怀孕，怀上龙凤胎的几率都是比较小的，不过做试管也有可能会生龙凤胎，做试管生龙凤胎需要的条件一般有以下这些：

- 1. 首先年龄不能太大，因为高龄患者如果做试管怀上了龙凤双胞胎，妊娠风险是比较大的，容易发生多胎妊娠综合征；
- 2. 子宫情况要好，如果子宫因素不宜双胎妊娠，做试管是不能移植两个胚胎的，即使怀上了双胞胎，也建议减胎；
- 3. 还有就是不能有全身性疾病，如果疾病不能有效控制，做试管怀龙凤双胞胎是很危险的；
- 4. 只有当试管移植两个胚胎都存活，且两个胚胎性别不一样，才能是龙凤胎，而这就只能纯靠运气，因为国家是禁止选性别生龙凤胎的。
龙凤胎就是双卵双胎，是由两个卵子分别受精形成的双胎。而做试管如果能够移植两个胚胎，那么都存活就很有可能是龙凤胎，不过也有可能是同性别的双胞胎。
